# Credit Card Fraud Detection Frontend

Next.js & Tailwind CSS dashboard for the Credit Card Fraud Detection System.

## Features

- **Dashboard Overview**: Key metrics (transactions analyzed, fraud detected, fraud rate, model accuracy).
- **Interactive Visualizations**: Risk score distribution and fraud trends over time.
- **Transaction Simulator**: Real-time fraud prediction form connected to the backend API.
- **Recent Transactions & Alerts**: Monitor flagged fraudulent transactions and details.

## Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- `npm` or `pnpm`

### Installation

```bash
cd frontend
npm install
# or
pnpm install
```

### Running Development Server

```bash
npm run dev
# or
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
